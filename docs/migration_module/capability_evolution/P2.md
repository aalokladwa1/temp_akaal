### P2.3 — Universal Datatype System & Rulebook Standardization
- **Canonical Datatype System ([`types.py`](file:///a:/temp_akaal/akaal/schema/domain/types.py))**: Implemented database-agnostic `CanonicalType` and `CanonicalTypeCategory` enum covering 22 semantic categories (`INTEGER`, `DECIMAL`, `FLOAT`, `BOOLEAN`, `CHAR`, `VARCHAR`, `TEXT`, `BINARY`, `VARBINARY`, `BLOB`, `DATE`, `TIME`, `TIMESTAMP`, `TIMESTAMPTZ`, `UUID`, `JSON`, `JSONB`, `XML`, `INTERVAL`, `ENUM`, `ARRAY`, `UNKNOWN`).
- **Conversion Safety Classification**: Implemented `ConversionSafety` classification (`EXACT`, `SAFE`, `POTENTIALLY_LOSSY`, `LOSSY`, `UNSUPPORTED`, `VENDOR_SPECIFIC`) attached to every target emission for downstream P2.7 risk analysis.
- **Universal Type Registry & Rulebook ([`type_registry.py`](file:///a:/temp_akaal/akaal/schema/domain/type_registry.py))**: Centralized 2-step type conversion pipeline: `Source Native Type → Source Adapter Normalizer → CanonicalType → Target Type Emitter → Target Native Type`.

### P2.3.1 — Datatype Semantic Acceptance Audit & Hardening
- **MySQL `TINYINT(1)` Semantic Hardening**: Hardened `TINYINT(1)` to preserve `INTEGER(bits=8)` by default unless explicit boolean evidence (`is_boolean=True`) is provided in metadata.
- **Oracle Parameter Ambiguity & Negative Scale**: Fixed type parameter parsing regex (`r"\(([\d\s,\-]+)\)"`) to support Oracle negative scale (`NUMBER(5,-2)`).
- **MSSQL `ROWVERSION` / `TIMESTAMP` Hardening**: Verified `ROWVERSION` normalizes to `VARBINARY(length=8, extra={"mssql_rowversion": True})` and emits `ConversionSafety.VENDOR_SPECIFIC` with warning when targeting PostgreSQL `BYTEA`.
- **Unsigned 64-Bit Range Overflow Protection**: Mapped MySQL `BIGINT UNSIGNED` to PostgreSQL `NUMERIC(20,0)` to avoid signed 64-bit integer overflow (`ConversionSafety.SAFE`).
- **Dynamic Plugin Extensibility**: Added `register_normalizer(engine, func)` and `register_emitter(engine, func)` on `CanonicalTypeRegistry`.

### P2.5 — Canonical Dependency Intelligence & Topological DDL Ordering

### P2.6 — Programmable Database Object Intelligence & Universal Conversion Engine
- **Canonical Programmable Authority ([`programmable_engine.py`](file:///a:/temp_akaal/akaal/schema/domain/programmable_engine.py))**: Implemented database-agnostic conversion engine `CanonicalProgrammableAuthority` generating `StructuredProgrammableArtifact` instances for Views, Materialized Views, Stored Procedures, Functions, and Triggers.
- **Elimination of Placeholder/Stub DDL**: Completely eliminated production placeholders like `CREATE VIEW ... AS SELECT 1 AS view_id;` and `BEGIN NULL; END;`.
- **Built-in Expression Rulebook (`SQLRulebook`)**: Translated common expressions (`NVL`/`ISNULL` → `COALESCE`, `SYSDATE`/`GETDATE()` → `CURRENT_TIMESTAMP`, trigger pseudo-tables `:NEW`/`:OLD` → `NEW`/`OLD` / `inserted`/`deleted`).
- **Complex Construct & Risk Detection**: Detected dynamic SQL (`EXECUTE IMMEDIATE`, `sp_executesql`), autonomous transactions, and PL/SQL packages, assigning `MANUAL_REVIEW_REQUIRED` status and `ConversionSafety.POTENTIALLY_LOSSY` / `VENDOR_SPECIFIC`.

### P2.6.1 — Programmable-Object Semantic Acceptance Audit & Hardening
- **Lexical-Safe Masking Utility**: Implemented `SQLRulebook.mask_literals_and_comments()` to mask string literals (`'NVL(val)'`) and comments (`-- SYSDATE is used`) before applying expression replacements, preventing text corruption.
- **Execution Firewall Enforcement**: Added `is_auto_executable` flag on `StructuredProgrammableArtifact` (set to `False` for `MANUAL_REVIEW_REQUIRED` or `UNSUPPORTED`). Refactored `SchemaExecutionStep` in [`migration_steps.py`](file:///a:/temp_akaal/akaal/workflow/steps/migration_steps.py) to block non-auto-executable artifacts from executing automatically.
- **MSSQL Multi-Row Trigger Warning**: Detected MSSQL `INSERTED`/`DELETED` set-oriented pseudo-tables and marked conversions as `MANUAL_REVIEW_REQUIRED` with explicit multi-row warnings.
- **Deterministic SHA-256 Fingerprints**: Verified source and conversion fingerprints are 100% deterministic across repeated runs.
